# Журнал изменений

Все заметные изменения проекта EISDiag описываются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [Не выпущено]

### Изменено

- В метке времени журнала `events.log` теперь есть год (`2026-10-15 13:12:08.123`): записи
  на стыке годов и после ротации журнала можно упорядочить.

### Исправлено

- Описание версии на eisapp.ru (`updates/eisdiag/latest`) отдаётся как текст в UTF-8, как у
  EISWM: в браузере русский текст больше не превращается в кракозябры.

## [0.1.1] — 2026-10-15

Технический выпуск: смена сервера обновлений.

### Изменено

- Обновления проверяются и скачиваются только с сайта eisapp.ru, к GitHub приложение за ними
  больше не обращается. Если APK не скачался с основного адреса, приложение пробует запасной.
- В Помощи, README и документации ссылка на GitHub заменена на сайт https://eisapp.ru/eisdiag.
- Публикация обновления на eisapp.ru из GitHub Actions при слиянии в `master`.

## [0.1] — 2026-10-05

### Добавлено

- Первая версия: экран «Диагностика машины», выделенный из EISWM в отдельное приложение
  `com.EISDiag`. Снимок свойств машины, запись событий в фоне с продолжением после сна и
  перезагрузки, отметки в журнале и сохранение файлов на флешку. Только чтение.
- Своя иконка приложения (шильдик Evolute с красной линией пульса) вместо иконки EISWM
  и такой же значок в уведомлении о записи.
- Иконка и логотип перерисованы в векторе по эталонной сетке точек, линия пульса опущена
  ниже среднего ряда и не закрывает самую мелкую точку.
- Логотип на верхней панели без круглого фона; в светлой теме точки синие.
- Кнопки «Тема» (авто, светлая, тёмная) и «Выход» на верхней панели, как в EISWM. «Выход» и
  системная «Назад» закрывают приложение; запись событий, если идёт, продолжается в фоне.
- Помощь: описание программы, версия, разработчик и лицензия; отказ от ответственности
  при первом запуске и из Помощи, как в EISWM.
- Обновления, как в EISWM: в шапке окна Помощи версия и «Проверить обновления»; проверка
  при запуске не чаще раза в сутки, загрузка с проверкой контрольной суммы и установка без
  системного установщика. Описание последней версии — `docs/updates/latest` на GitHub Pages.
- Инструкция пользователя со скриншотами — `docs/INSTRUCTION.md`, ссылка в README.

### Изменено

- README сокращён до описания для пользователя: что это, установка, ссылка на инструкцию,
  лицензия и отказ от ответственности. Технический разбор (устройство приложения, API машины,
  как работает диагностика, происхождение из EISWM, сборка, обновления, ветки) перенесён
  в `ANALYSIS.md`.
- Отметка, снимок машины, сохранение файлов и очистка журнала перенесены на верхнюю панель
  в виде значков (название — по долгому нажатию), слева на панели — значок приложения.
  Очистка журнала спрашивает подтверждение.
- Размер APK уменьшен с 2,7 МБ до 115 КБ: выключен встроенный в AGP 9 Kotlin, который
  добавлял в Java-проект библиотеку kotlin-stdlib, а в release включены R8 и удаление
  неиспользуемых ресурсов.
- Рефакторинг Java-кода без изменения поведения: общий цикл копирования файлов, общие
  создание подписей и очистка папки обновлений, один слушатель на все свойства машины
  вместо сотен одинаковых, проверка библиотеки машины запоминается (на эмуляторе экран
  не создаёт исключение каждые 2 с), журнал не создаёт форматтер времени на каждую строку.

### Исправлено

- Сохранение файлов на флешку: окно выбора папки отклоняло флешку («В эту папку нельзя
  записывать»), а копирование молча падало. Теперь запись идёт через /mnt/media_rw
  (разрешение WRITE_MEDIA_STORAGE), при сбое ФС флешки файл пишется напрямую, а при ошибке
  в сообщении видна её причина.
