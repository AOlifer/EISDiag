# EISDiag — Evolute I-Space Diagnostics

«Диагностика машины» — приложение для головного устройства Evolute i-Space (прошивка Yato1,
Android 9). Показывает, какие данные и события машины доступны приложениям: делает снимок
состояния, записывает события в журнал и сохраняет файлы на флешку. Только чтение — в машину
ничего не записывается. Значения токенов, номеров, адресов, идентификаторов и VIN в файлы
не попадают.

## Установка

1. Скачайте APK последней версии со страницы
   [Releases](https://github.com/AOlifer/EISDiag/releases).
2. Установите его на головное устройство с флешки или командой `adb install -r`.

Приложение отдельное от [EISWM](https://github.com/AOlifer/EISWM) («Менеджер приветствия»),
их можно держать одновременно. Следующие версии приложение ставит само: «Проверить обновления»
в шапке окна Помощи.
